# Phase 1: foundation (status)

## Built

- pnpm monorepo: `apps/web`, `packages/core`, `packages/db`.
- **Design system:** colour tokens with fixed meanings (blue for mainnet, violet for testnet, cyan for live), Geist type, shared Button, Badge and Panel components, visible focus states, and reduced-motion support.
- **Homepage:** a hero whose network map is drawn from the real registry, an explanation of testnet and mainnet modes, a product roadmap, a public metrics table (honest "Data not yet available"), security commitments, a partner note with no fake logos, an FAQ and a footer with a risk disclaimer.
- **Public pages:** `/chains` (live registry status), `/analytics` (metric definitions, nothing invented), `/docs` with 5 guides, and honest "not available yet" pages for Swap, Bridge, Airdrop Hub, Campaigns and Leaderboard.
- **Wallets:** wagmi + RainbowKit on Ethereum, Base, Arbitrum, Sepolia and Base Sepolia. WalletConnect is used when a project ID is set.
- **Sign-in:** SIWE with single-use nonces, domain and URI binding, a server-side session table, logout revocation, an Origin check and rate limits.
- **Database:** Prisma 7 schema and the first migration (15 tables). Database triggers make audit logs append-only and fee configurations immutable, with a CHECK on fee rates.
- **Seed:** 5 chains, 3 provider candidates (0x, Uniswap API, LI.FI) and 8 canonical tokens, all disabled.
- **Admin:** RBAC, an overview with real counts, a chain on/off switch, and the token registry. Adding a token runs an on-chain decimals and symbol check plus impersonation detection, and a token must be verified before it can be turned on. There is also an audit log viewer. Wallets listed in `ADMIN_BOOTSTRAP_ADDRESSES` become Super Admin on first sign-in.
- **CI:** GitHub Actions runs install, Prisma generate, typecheck, lint, tests and build.

## Verified

- 25 unit tests pass: fee engine, registry validation, RBAC, metrics, SIWE checks and signatures, rate limiting.
- Typecheck, lint and production build pass.
- The migration was generated by Prisma's own schema engine and applied to an embedded PostgreSQL 17 (PGlite).
- Database protections were tested: audit-log update blocked, fee-rate edit blocked, fees above 5% blocked, fee close-out allowed.
- An end-to-end run of the built server covered:
  - admin sign-in and the bootstrap grant;
  - rejection of a replayed signature, a foreign-domain message and a request with no Origin;
  - admin chain toggle, which correctly does **not** make the chain publicly live;
  - token validation and flagging;
  - a normal user being refused admin access;
  - logout revoking the session;
  - audit log entries for all of the above.
